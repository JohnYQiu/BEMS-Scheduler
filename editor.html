    Guide / Source of truth

    How it works

    Four pieces work together. This page handles policy and manual coverage, not live imports or schedule generation.

    Where does availability come from?

    Officers download responses from Google Forms as CSV or ZIP files. Those downloaded files are the availability input. This local editor does not read a live Google Form, Drive file, or Sheet, and it does not sync changes back to Google.

    What does this page control?

    The supervisor's ALS/BLS calendar is entered manually in the grid. Dates, forced crews, policy settings, optional implemented rules, and priority order are saved to the local configuration. Other source data is not changed here.

    What is a hard rule versus a priority?

    Hard rules must be met, such as availability, credentials, safety, and rest. Priorities guide how the scheduler chooses among valid schedules. Moving a priority cannot waive a hard rule. Only supported rules in the library can be enabled; a proposed rule needs a Python implementation before it affects a schedule.

    What happens after I save?

    The Python solver uses the downloaded availability files and local configuration to build candidate schedules. Review its output and any warnings before sharing or publishing. Saving this page alone does not generate, approve, or publish a schedule.
